# RehelpWeb

## Quick running app

* `npm install`
* `npm test`
* navigate to `http://localhost:4200`

## Technology Stack

* NodeJs
* Express Framework
* Angular
* Postgresql
* Sequelize

## Install Postgresql

### MacOS

* `brew doctor`
* `brew update`
* `brew install postgresql`
* start it with `brew services start postgresql`, stop it with `brew services stop postgresql`
* run cli with `psql`

## Postgresql Commands

* `\q` exit
* `\list` list databases
